# Time Table Management System

A simple web-based Time Table Management System developed using PHP and MongoDB.  
This project helps users manage class timetables and exam datesheets easily.

---

# Features

- User Registration and Login
- Secure Authentication System
- Home Dashboard
- Timetable Management
  - Add Records
  - Edit Records
  - Delete Records
  - View Records
- Date Sheet Management
  - Add Exam Schedule
  - Edit Schedule
  - Delete Schedule
  - View Schedule
- Form Validation for correct user input

---

# Technologies Used

- PHP
- MongoDB
- Bootstrap 5
- HTML
- CSS
- JavaScript
